📊 의사결정나무 깊이별 오차(MAE) 비교 대시보드

나무의 깊이가 깊어질수록 학습 오차는 계속 줄어들지만, 평가 오차는 U자형 곡선을 그리며 과적합(Overfitting)이 발생합니다.

💡 분석 인사이트:
• 깊이 2 (과소적합): 모델이 너무 단순하여 학습 오차(42.58건)와 평가 오차(42.09건)가 모두 높습니다.
• 깊이 8 (최적 균형): 평가 오차가 33.08건으로 나무 모델 중 가장 낮으며, 일반화 성능이 가장 우수합니다.
• 깊이 제한 없음 (극심한 과적합): 학습 데이터를 100% 외워 학습 MAE는 0.00건이지만, 새로운 평가 데이터 오차는 39.78건으로 크게 반등합니다.
